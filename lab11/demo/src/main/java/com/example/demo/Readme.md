Compulsory + Homework:

Am facut un proiect Spring Boot in care am implementat urmatoarele entitati: Game, Player, Question si Result, impreuna cu relatiile many-to-many si one-to-many si many-to-one dintre ele.
Pentru fiecare model am facut si cate un Repository.
In PlayerRepository am facut un read query, care afiseaza toti jucatorii ordonati descrescator dupa scor, si un modifying query care modifica scorului unui jucator.
Clasa Auditable este extinsa de catre fiecare model, pt a avea informatii despre cand s-au inserat informatii in tabele si cand s-au modificat.
